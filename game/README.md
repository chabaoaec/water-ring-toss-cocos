# 口袋潮汐 / Pocket Tide

一台可在桌面和手机浏览器里玩的复古水中套圈玩具。奶油白塑料壳、浅青玻璃水箱、珊瑚色双按钮；原创程序绘制，无外部美术或运行时网络请求。

**实际使用 Cocos Engine 3.8.7**：`cc.Scene`、`cc.Node`、`cc.Canvas`、`cc.Camera`、`cc.Graphics`、`cc.Sprite` 和 `cc.Component.update` 负责场景、WebGL2 绘制和游戏循环；**cannon-es 0.20.0** 负责真正的三维刚体。没有用 Canvas2D/Phaser/Three.js 替代 Cocos。这里是开源引擎独立启动的 Web 游戏，不声称经过 Cocos Creator 编辑器构建，也不是可直接打开的 Creator 场景工程。

## 快速运行

需要 Node.js 20+，浏览器需要 WebGL 2（当前 Chrome/Edge/Firefox/Safari 通常支持，实际设备仍须验证）。不要直接双击 HTML，ES Modules 需要 HTTP。

```sh
cd game
npm ci
npm test
npm run build
npm start
# 浏览器打开 http://127.0.0.1:8080
```

`npm run build` 检查游戏模块语法并组装 `dist/`，包含已经从官方固定源码编译、随仓库保存的真实 Cocos 引擎。`dist/` 是完整静态网站，可通过任意普通 HTTP 静态服务运行，没有服务器业务、账号、广告或支付。`PORT=8081 npm start` 可改端口；需要局域网手机访问时可显式 `HOST=0.0.0.0 npm start`。

## 操作

- 轻点左/右按钮，或键盘 **A / ←**、**D / →**，喷出低速小股水流；持续按住约半秒，压力、流速和推力逐渐增强。支持左右同时按、多点触摸。
- 每侧每次按压只有一份有限水量，满压前后合计约1秒耗尽。耗尽会停止物理喷流并显示“松开补水”；该侧全部手指/按键松开后，吸水口在约0.7秒内逐渐补满泵腔；未满就再按仅使用已有水量。持续长按、键盘自动重复或额外叠加同侧输入都不会续喷。左右水量独立。
- 松手后，水阻让彩环缓慢下沉。试着让真正的环孔越过柱顶，等待它沿柱落稳。
- 彩环实际穿柱，并由该柱底座的真实向上接触或由底座承托的环堆支撑，低速稳定 **0.7 秒**才计分。悬浮在柱中段、碰柱侧面或两只漂浮环相互接触都不构成落稳。喷流仍可重新抬起已落稳环，分数随真实状态变化。
- 八个彩环全部稳定套入即获胜，显示耗时和喷流次数。没有倒计时、失败惩罚或付费点。
- 点击顶部菜单可暂停；点击“继续游玩”、顶部“返回”或 Esc 可继续。“重新开始”仅在菜单内，须明确点击。声音默认关闭，可在菜单开启，由浏览器合成。
- 页面失焦、隐藏或触摸取消会释放喷流，避免按钮卡住。减少动态效果偏好会减少亮片数量并关闭闪烁旋转，保留核心物理。

## 物理与画面边界

每个环由 **24 个重叠球体**组成有孔的刚性圆环；两柱为真实圆柱，底座和六面水箱为静态刚体。环与环、柱、箱壁都经过 Cannon 碰撞求解。固定物理步长 1/120 秒，水下重力与近似浮力、速度阻力、旋转阻尼、共享喷流/回流速度场产生上浮、翻转、碰撞与下沉。宽面水阻用弱的回正力矩近似。环与环使用约0.52恢复系数，环碰柱/壳约0.10；真实碰撞会弹开并翻转，水阻随后消能，没有软体变形或视觉假弹开。

计分根据柱轴与当前四元数定义的环平面相交，使用交点高度的锥柱半径、倾斜截面和安全余量保守检查环孔包围。支撑图只从对应真实底座出发，沿向上受载接触传递给更高环；未穿柱但坐在底座上的环可以承托已穿柱环，漂浮闭环不能自证支撑。不会按屏幕距离吸附、传送或焊接到柱上。画面把同一三维刚体姿态投影为略俯视的 2.5D 圆环，按深度分段排序，保留前后遮挡和厚度。全水箱亮片是被动示踪：与彩环水阻共用解析循环速度场，以中点法输运，没有回家弹簧、寿命换生或为均匀分布而随机重置。普通模式共128粒，减少动态效果36粒；其中一部分随水进入泵腔，排水后再从喷嘴出现，身份与总数不变，可见数量随泵内水量变化。

水箱初始水量48、左右泵各0.8，总量49.6；排水使水位从520最高升至536.267，松手补泵时下降，保留上方空气区。循环流速包含共享的惯性幅度：泵腔耗尽或松手后，水体回流仍会继续并在数秒内耗散；实际排水/吸水质量通量随泵状态停止，不凭空增加水量。这是低维指数松弛近似，不是完整动量方程。解析速度场包含喷嘴上升流、下降回流、底部管口交换和移动水面的通量，不是真实流体/流固耦合求解器。格栅到箱底管口的内部管路没有建模；倾斜水面由保持水量的箱体截平面求解，空气区随方向移动；仍不是压力/晃荡方程。斜面上的实际泵源汇位移场保留运动学近似，示踪的固壁/自由面反射不等于完整不可压缩流体解。彩环按浸没比例承受浮力和水阻，浮力与当前重力方向相反。复合球体是环面碰撞近似，并非精确连续网格。

手机倾斜与摇晃默认开启。支持免授权读取的浏览器会等待有效数据后自动校准；需要权限的浏览器须在菜单点击“授权传感器”，权限通过之前不会假装已生效。可校准舒适握持姿势、关闭恢复普通向下重力；桌面按钮和键盘照常使用。手机远程访问须HTTPS；仅电脑自身localhost属于安全上下文。线性加速度与重力方向分开：优先读取浏览器去重力加速度，保留幅值并经过短时滤波；缺该通道时使用明确标注的高通估计，持续慢移与倾斜仍有歧义。加速度在箱体参考系对水和圈产生相反方向的惯性响应，停止输入后水流衰减；150ms 无新加速度读数就清除持续输入，暂停/重开不残留旧摇晃。菜单里的“暂停中”和“等待读数”与实际启用分开。合成读数和本地浏览器检查不能代替手机真机验收。


## 从官方源码重建引擎

普通运行无需下载引擎源码。需要审查或重建时：

```sh
npm run bootstrap
npm run build:engine
npm run build
npm test
```

`bootstrap` 下载官方固定 commit 的约 86 MB 源码包，先核对 SHA-256，再只在项目目录使用上游锁文件 `npm ci --ignore-scripts` 安装构建依赖。引擎源码在 `vendor/cocos-engine/`，不进入 Git。未执行编辑器/native 的 postinstall，也未安装任何全局软件。构建使用官方 `@cocos/ccbuild`，只启用 base、WebGL2、2d、graphics、legacy-pipeline。选择 Chrome 90 语法目标以规避旧 ES5 变换的局部循环变量问题。

完整来源、commit、哈希、模块和编辑器边界见 [ENGINE-SOURCE.json](ENGINE-SOURCE.json)。源码未修改；[src/engine-bootstrap.js](src/engine-bootstrap.js) 在项目侧把官方测试夹具中的预编译 GLSL4 声明适配为 WebGL2 GLSL3，并使 `CCGlobal` 布局与当前引擎一致。只提供 WebGL2；未宣称 WebGL1、原生 App 或 Creator 导入已验证。MIT 及依赖声明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 验证与文件

`npm test` 用 Node 内建测试器直接运行真实 Cannon 世界，覆盖有限喷流、回补、水量/粒子身份守恒、循环流量、碰撞、环孔穿柱、真实支撑和传感器生命周期。版本证据见 `evidence/v5.3/`（v5.2 及更早保留）；旧版本的失败和验证范围保留在 `evidence/v2/` 至 `evidence/v4.1/` 及仓库根 `VALIDATION.md`。浏览器脚本需要外部已有 Playwright/Chromium，项目不会自动安装浏览器。

- `src/physics.js`：三维刚体、水量账和真实支撑计分。
- `src/recirculating-flow.js`：解析循环场、底部交换管口和移动水面通量。
- `src/fluid-tracers.js`：固定身份被动示踪及泵腔运输。
- `src/gravity-input.js`：默认开启的倾斜与线性加速度、权限、滤波和校准。
- `src/inertial-water.js`：与圈/示踪共享的衰减惯性循环场。
- `src/water-surface.js`：保持水量的三维静水自由面与截面几何。
- `src/water-parcel-boundary.js`：水示踪的固壁/自由面反射边界。
- `src/render.js`：Cocos Graphics 主场景及共用纹理的池化亮片 Sprite。
- `src/input.js`：键盘/触摸聚合、释放和取消边界。
- `src/main.js`：Cocos游戏循环、菜单状态与音效。

`window.__waterToy` 供浏览器检查引擎版本、场景和物理世界，没有自动获胜或强制计分功能。合成传感器读数不等于真机验证；Chromium/SwiftShader软件渲染不代表用户Brave硬件帧率。完整手动8/8通关、iOS/Android真机、其他浏览器、低端设备性能、离线PWA和原生封装均未完成验收。

## v5.3 版本核对

界面右上角应显示 `DEMO v5.3`。完整试玩包解压后运行 `python3 start-demo.py`，使用独立8088端口并禁止缓存。脚本固定读取自身目录，端口占用会明确报错；不要把旧服务或旧标签页当成新版。


v5.2 将六面碰撞内壁与流体域对齐，并修正底部回流朝向。Cannon 复合球环的静体接触摩擦按总受载接触补丁分摊冲量预算，避免给每个小球重复一份摩擦；保留碰撞恢复系数、圈间摩擦和真实受载支撑计分。这是外力法向载荷估计，不是完整多体接触压力求解。8 个边角姿态、10/20/30°底圈滑移、短时摇晃与水流余动、一次普通有限按压后真实落柱已覆盖；不保证任意操作都通关。构建会给入口和传递导入统一内容版本参数，减少新版页面混用旧模块。


v5.3 保留转屏前的校准坐标，支持完整倾斜和倒置；转屏不再隐式把当前姿势当作朝下，菜单显式校准仍可设置新基准。原有方向平滑和摇晃的物理加速度保持。原生 AABB 碰撞预筛选跳过远距离假候选，不改24球环、120Hz步频、材质、可见粒子或真实接触计分。95项联合测试通过；9840对旧/新碰撞筛选步骤状态相同。开发环境物理耗时降低不代表实际手机卡顿已解决；手机硬件FPS仍待实测。
